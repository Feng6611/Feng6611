# Hi, I'm chenfeng

I build small, focused Mac apps — tools that do one thing well and ask for
as few permissions as possible. Ideally none.

## Mac apps

| App | What it does |
|---|---|
| **[Command Reopen](https://commandreopen.com)** | Fixes Cmd+Tab: restores minimized and closed windows when you switch apps. Zero permissions, sandboxed. [Mac App Store](https://apps.apple.com/app/id6757333924) · [Source](https://github.com/Feng6611/mac-command-reopen) |
| **[Clipboard Drop](https://apps.apple.com/app/id6768068044)** | Sends copied text to a nearby Apple device over AirDrop — works across different Apple IDs, no cloud, nothing to install on the receiving end. [Source](https://github.com/Feng6611/mac-airdrop-clipboard) |

Both are sandboxed Mac App Store apps with public source — you can audit
exactly what they do, and what they don't.
